# RULES: urban-weekly-dashboard

전체 규약을 따르되, 이 프로젝트만의 추가 규칙:

## 폴더

| 폴더 | 성격 | 수정 |
|---|---|---|
| `data/` | Confluence 수집물 (페이지·첨부·파싱본) | ❌ 재수집으로만 갱신 |
| `workspace/` | 설계·중간 작업 | ✅ 자유 |
| `output/` | 대시보드 산출물 | ⚠️ 확정 후 |
| `scripts/` | 이 프로젝트 전용 스크립트 | ✅ 자유 |

- 수집 원본의 단일 출처는 **Confluence**다. `data/`를 직접 고치지 않는다.
- 수집기는 저장소 공용 `scripts/confluence-browser-sync.py`를 쓴다.

## 데이터 취급

- **조직명은 반드시 `data/부서_정규화.json`을 거쳐 집계한다.** 원본 표기(`org_raw`)도 함께 보관해
  매핑이 틀렸을 때 되돌릴 수 있게 한다.
- `확인필요: true`인 조직은 **임의로 합치지 않는다.** 별도 항목으로 두고 확인 요청을 남긴다.
- 주간보고는 개인의 업무 기록이다. 특정 인물의 성과 평가나 비교 목적으로 가공하지 않는다.
- 첨부에 계약·인사·급여 자료가 섞여 있을 수 있다. 대시보드에 노출 전 성격을 확인한다.

## 수집

- 브라우저 세션이 끊기면 수집기가 빈 응답을 반복 시도한다. **연속 실패 시 중단하고 세션부터 확인한다.**
- 대용량 첨부(기본 8MB 초과)는 목록만 남기고 건너뛴다. 필요한 것만 개별로 받는다.
