3. **6,000건은 자체 목표다.** "발주자 목표"로 쓰지 말 것. 계약 요건은 3,000건.

## content.json 스키마 (agyx가 채울 것)

```json
{
  "meta": {"title": "...", "subtitle": "...", "date": "2026-07-27",
           "org": "㈜어반데이터랩", "partners": "㈜포트래이 · 길의료재단"},
  "slides": [
    {
      "no": 3,
      "type": "kpi_table",
      "eyebrow": "ACHIEVEMENT",
      "title": "결론을 한 문장으로. 40자 이내",
      "kpis": [
        {"label": "수집 이미지", "value": "6,122", "unit": "건",
         "note": "계약 3,000건 대비 204%", "watch": false}
      ],
      "table": {"head": ["구분","..."], "rows": [["...","..."]]},
      "bullets": ["문장 1", "문장 2"],
      "source": "출처 표기 문구"
    }
  ]
}
```

규칙:
- `title`은 **결론**을 쓴다 (design.md §10.1). "현황"·"개요" 같은 명사형 금지.
- `kpis`는 슬라이드당 최대 4개. `watch: true`는 **한 장에 하나만** (강조색은 한 의미).
- `bullets`는 한 항목 60자 이내, 최대 5개.
- 모든 수치에 `source`를 적는다.
- 미달·지연 항목을 숨기지 않는다. 특히 임상연계 0%와 리뷰 32.6%는 명시한다.

## codexx 구현 요구사항

`build_deck.py`는 `content.json`을 읽어 네이티브 pptx를 생성한다.

- `sys.path`에 `scripts/` 추가 후 `from udl_pptx import Deck, T`
- **이미지는 사진만 삽입** (design.md §12.3). 도형·텍스트·표는 네이티브 개체.
- 필요한 신규 컴포넌트: `image_card(x,y,w,h,path,caption)` — 사진 + 캡션 바.
  사진은 비율 유지 크롭(cover), 라운드 14px, 캡션은 하단 좌측 `caption` 스타일.
- 타임라인 컴포넌트: 월별 6칸, 각 칸에 월 라벨 + 핵심 성과 1~2줄.
- 테마는 `dark` 하나로 생성 (라이트는 후속).
- 슬라이드 번호는 우하단 푸터에 자동 삽입.
- 실행: `python3 build_deck.py content.json 중간보고_초안_v1.pptx`
