## 결론 — 병리 트랙은 맞고, 공간전사체는 MeDIAuto를 거치지 않습니다

원문 어디에도 **Xenium 공간전사체 데이터를 MeDIAuto에 올린다는 기술이 없습니다.**
MeDIAuto는 **병리 이미지(WSI) 전용 플랫폼**이며, 공간전사체는 별도 경로로 질병청에 직접 제출됩니다.

### 근거 1 — 연차실적계획서의 MeDIAuto 역할 기술

> "본 과업에서 해당 세부가 진행하고자 하는 **디지털 병리 이미지 정보 전처리 및 라벨링**을 위해
> 본사에서 보유중인 **어노테이션 플랫폼(MeDIAuto)**을 활용하고자 함"

기술된 기능이 전부 병리 이미지 처리입니다. 공간전사체 언급이 없습니다.

### 근거 2 — 공간전사체의 실제 경로 (월간회의자료)

> "2026년 데이터는 8월 중에 Raw data, Processed data에 대해서 모두 제출 완료 가능"

포트래이가 생산해 **질병청에 직접 제출**합니다. MeDIAuto 경유 기술이 없습니다.

### 근거 3 — MeDIAuto 시스템 실측 (2026-07-27 조사)

| 코드 | 대상 |

공간전사체 프로젝트, Xenium 데이터, 전사체 뷰어가 **시스템에 존재하지 않습니다.**

## 원문으로 확인한 실제 데이터 흐름

### 트랙 A — 병리 이미지 (어반데이터랩 · MeDIAuto)

```
길병원(GH)                MeDIAuto (어반데이터랩)              산출
──────────                ──────────────────────              ────
원본 MRXS (WSI)  ──────▶  ① 비식별화 TIFF 자동 변환      ──▶  AI 학습용
병리전문의 어노테이션 좌표      · 기관별 스캔 규격 표준화            정제 데이터(GT)
                             · 환자 식별정보 자동 제거
                          ② 어노테이션 좌표 매핑·검증
                          ③ 영역 라벨링 (tumor 단일 클래스)
                          ④ 병리 전문의 리뷰 → Termination
```

- 병원은 **GH(가천대 길병원) 단독**입니다.
- 라벨 클래스는 현재 tumor 단일이며, stroma·necrosis·inflammation 확장을 검토 중입니다.
- 전립선암 데이터는 **HDD로 수령**했습니다 (네트워크 전송 아님).

### 트랙 B — 공간전사체 (포트래이 · Xenium)

```
길병원                    포트래이                          질병관리청
──────                    ────────                          ──────────
파라핀 블록  ──송부──▶  Xenium 5K Prime Panel 실험  ──▶  Raw + Processed
                          데이터 생산                        직접 제출
```

- MeDIAuto를 **경유하지 않습니다.**
- 2025년분 26건은 12월 말 제출 완료, 2026년분은 8월 중 제출 예정입니다.

### 두 트랙의 접점

계약상 **"디지털 병리 이미지 ↔ 공간전사체 연계 모델 검증"**(요구사항 ④)이 두 트랙을 잇는 지점입니다.
어반데이터랩은 WSI–ST 좌표 매칭용 병리 GT를 제공하고, 길병원(제3세부)이 연계 모델을 개발·검정합니다.
