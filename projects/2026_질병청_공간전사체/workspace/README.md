# workspace — 작업 폴더

**여기가 유일하게 파일을 만들고 고쳐도 되는 곳입니다.**

## 폴더 4계층과 규칙

| 폴더 | 성격 | 수정 | 용도 |
|---|---|---|---|
| `source/` | Drive 원본 미러 | ❌ 절대 금지 | 사실 확인의 기준. 갱신은 Drive에서 다시 가져오기 |
| `parsed/` | 파싱 파생물 | ❌ (재생성됨) | 에이전트·사람이 내용을 빠르게 읽는 용도 |
| `workspace/` | **작업 영역** | ✅ 자유 | 문서 작성·수정·분석. 여기서만 편집 |
| `output/` | 확정 산출물 | ⚠️ 확정 후 | 외부 제출·공유용. Drive 업로드 대상 |

원본을 고쳐야 하는 작업은 **원본을 고치는 게 아니라 `workspace/`로 복사해 새 버전을 만드는 것**입니다.

## 작업 흐름

```
source/ (원본)  ──복사──▶  workspace/ (편집)  ──확정──▶  output/  ──업로드──▶  Google Drive
```

1. **가져오기**: `scripts/pull-source.sh <프로젝트경로> <source 내 경로> <workspace 하위폴더>`
   원본을 `workspace/_원본사본/`에 복사하고 출처·해시를 `_출처.md`에 기록합니다.
   (직접 복사해도 되지만, 출처 기록이 남지 않으므로 스크립트 사용을 권장)
2. **편집**: `workspace/01_보고` 등 해당 폴더에서 작업
3. **확정**: 완성본을 `output/`으로 옮기고 파일명에 날짜·버전 표기
4. **반영**: `output/`의 확정본을 Google Drive 해당 위치에 업로드 (수동)

## 하위 폴더

| 폴더 | 용도 |
|---|---|
| `01_보고/` | 월간회의 자료, 중간·최종 보고서, 연차실적계획서 작성 |
| `02_정산/` | 사업비 정산, 증빙 정리, 산출내역 계산 |
| `03_데이터점검/` | 수집·라벨링 실적 집계, MeDIAuto 대조, 수치 검증 |
| `04_회의/` | 회의록, 협의체 안건·후속조치 |
| `_원본사본/` | `source/`에서 가져온 편집 기반 파일 (출처 기록 포함) |

## 지켜야 할 것

- `source/` 안의 파일을 열어 저장하지 않습니다. 실수로 저장하면 Drive와 어긋납니다.
- 수치를 인용할 때는 출처 파일명을 함께 적습니다 (`RULES.md` 참조).
- 개인정보가 포함된 자료(급여명세서·통장사본 등)는 `workspace/`로 복사하지 않습니다.
  부득이한 경우 합계·건수만 옮겨 적습니다.
- `workspace/`는 git에 커밋됩니다(대용량 바이너리 제외). 진행 상황이 이력으로 남습니다.
