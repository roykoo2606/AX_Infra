### npm 실패 원인과 조치

`EACCES: permission denied` — `~/.npm/_cacache`에 **root 소유 파일**이 섞여 있었다(과거 `sudo npm` 흔적).
sudo 없이 별도 캐시로 우회해 해결.

```
npm install --cache /tmp/npm-hermes-cache      # 워크스페이스 1,303 패키지
cd web && npm install --cache /tmp/npm-hermes-cache && npm run build
```

→ 웹 UI 빌드 성공. `hermes web` 사용 가능.
