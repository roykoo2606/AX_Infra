# 2026-07-27 agyx 재시작 시 자동 기동 구성

- 지시: cmux 재시작 시 agyx가 자동 기동되도록 스크립트 구성 (출처: 대화)
- 조사:
  - cmux 네이티브 `surface resume set`으로 바인딩을 걸 수 있으나, CLI가 만든 바인딩은
    `auto_resume=false`(approval_policy=manual)로 저장되어 재시작 시 자동 실행 안 됨
    (agent-hook이 만든 바인딩만 auto — agyx는 훅 금지라 이 경로 불가)
- 조치:
  1. agyx surface에 표식용 바인딩 설정: `cmux surface resume set --surface surface:2 --kind antigravity
     --name agyx --cwd ~/Claude/Projects/AX_Infra -- ~/.local/bin/agyx`
     (기존에 남아있던 훅 시절 바인딩은 옛 대화 ID에 고정돼 있어 교체)
  2. `scripts/agyx-autoboot.sh` 작성: cmux 패널의 새 셸 시작 시 현재 surface의 resume 바인딩이
     `kind=antigravity`면 agyx 실행. 가드: CMUX_SURFACE_ID 존재, AGYX_AUTOBOOT_DONE 1회 실행, cmux CLI 존재
  3. `~/.zshrc` 말미에 소싱 라인 추가
- 검증(드라이런, AGYX_AUTOBOOT_DRYRUN=1):
  - agyx surface UUID로 실행 → "would launch agyx" 출력 ✓
  - claude 패널(surface:1) → 무반응 ✓ (kind=claude라 스킵)
  - cmux 밖 셸 → 무반응 ✓
- 산출물: scripts/agyx-autoboot.sh, ~/.zshrc 소싱 라인, docs/usage.md 갱신
