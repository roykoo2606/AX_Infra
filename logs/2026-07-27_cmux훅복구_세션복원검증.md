# 2026-07-27 cmux Claude 훅 복구·세션 복원 재검증

- 지시: cmux 재기동 시 패널 에이전트가 과거 이력을 유지한 채 자동 로딩되지 않는 원인 진단·복구 (출처: 대화)
- 원인: cmux 설정 `claudeCodeHooksEnabled = 0` (Claude Code hooks 토글 꺼짐, 2026-07-08 13:16 이후 추정 — antigravity 훅 정리 무렵 실수 또는 업데이트 리셋).
  이 설정이 꺼지면 모든 패널에 `CMUX_CLAUDE_HOOKS_DISABLED=1`이 내려가고, cmux-claude-wrapper가 `--session-id`/`--settings` 주입 없이 통과시켜
  `~/.cmuxterm/claude-hook-sessions.json`에 세션이 기록되지 않음 → 재기동 시 복원할 세션 정보 자체가 없었음.
  codex 훅은 정상(플래그 주입 확인)이었으나 7-13 종료 시점에 surface 매핑이 비어 있어 이번 재기동에서 복원 대상 없음. agyx는 설계상 수동(훅 설치 금지, 2026-07-08 결정).
- 조치: Roy가 Settings에서 Claude Code hooks 재활성화(`claudeCodeHooksEnabled = 1` 확인).
- 검증(2026-07-27 11:15):
  1. 테스트 패널 신규 생성 → `CMUX_CLAUDE_HOOKS_DISABLED` 사라지고 claude가 cmux 래퍼 함수로 잡힘 확인
  2. 테스트 패널에서 claudex 실행 + 프롬프트 1회 → `claude-hook-sessions.json` 즉시 갱신, 해당 surface에 sessionId 매핑 생성
  3. `cmux list-panels`에서 해당 surface에 `resume_binding{auto_resume: true}` 생성 확인 → 테스트 패널 정리 완료
  4. 기존 codex 패널에도 오늘자 `resume_binding{auto_resume: true}` 활성 확인
- 남은 검증: ⌘Q → 재실행 시 claude·codex 패널 자동 재개 (Roy 확인 대기).
  주의: 현재 떠 있는 claude 패널(메인)은 훅 꺼진 상태로 기동된 세션이라 이번 1회는 자동 복원 안 됨 — 재시작 후 메인 패널에서 `claudex -c`로 이어받으면 다음부터 자동
